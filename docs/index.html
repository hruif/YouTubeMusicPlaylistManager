A native desktop app: sign in once in-app (no header copying), edit playlists, and import from Spotify. Ships as a universal .dmg (Apple Silicon + Intel) — open it and drag the app to Applications, then use Open Anyway on first launch (it isn't notarized yet). The original Python app is still available here.

What It Does

  • Imports public YouTube Music and Spotify playlist URLs.
  • Shows combined song lists from selected playlists with sorting and search.
  • Finds duplicate songs across selected playlists, including repeats inside one playlist.

Install Notes

  1. Download the latest .dmg from GitHub Releases (universal — Apple Silicon + Intel).
  2. Open the .dmg and drag YouTube Music Manager to your Applications folder.
  3. The app isn't notarized by Apple, so macOS blocks it on first launch. The simplest fix: double-click the app once (it gets blocked), then open System Settings → Privacy & Security, scroll to the Security section, and click Open Anyway next to "YouTube Music Manager."
  4. Alternatively, clear the quarantine flag in Terminal, then open it normally:
    xattr -dr com.apple.quarantine "/Applications/YouTube Music Manager.app"
    (On older macOS you can also Control-click the app and choose Open.)

Built For Playlist Cleanup

This app is a personal tool for making playlist maintenance less tedious: select the playlists you care about, view the combined songs in one place, search within the display, and open detailed song or playlist information when you need to untangle duplicates.
